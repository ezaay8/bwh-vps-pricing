建议从 40G 或 80G 开始看。

### 高并发或多个服务

不要只凭网站数量判断。两个低流量网站和一个高并发应用，对服务器的要求可能完全不同。更可靠的办法是观察 CPU 使用率、内存占用、磁盘空间、数据库响应和流量消耗，再决定是否升级。

## 价格之外，还要看哪些限制？

### 1. 价格是美元

官网价格以美元展示。信用卡、PayPal 或其他付款方式可能产生汇率差、发卡行手续费或税费。最终人民币成本会随着汇率变化，不宜把美元数字直接当成人民币预算。

### 2. 自助管理不是托管服务器

搬瓦工提供的是 VPS 主机资源，不是帮你维护网站的全托管服务。你需要自己处理：

- Linux 系统更新
- SSH 密钥和密码安全
- 防火墙设置
- Web 服务配置
- 数据库备份
- 网站迁移
- 异常流量和日志排查

如果只想上传网站、后台点几下就完成全部运维，VPS 可能不是最省事的选择。

### 3. 机房和线路会影响实际体验

同一个配置放在不同机房，访问延迟和网络表现可能不同。页面中的“Multiple locations”表示方案支持多个位置，但具体可选机房、库存和迁移规则仍要以购买页面显示为准。

购买时不要只看 CPU、内存和磁盘，也要确认：

- 目标用户主要在哪个地区
- 需要哪个机房
- 当前机房是否有库存
- 后续能否迁移
- 月流量是否够用
- 端口速度是否符合应用需求

### 4. 流量额度不是无限的

20G 套餐每月 1TB，40G 为 2TB，80G 为 3TB，160G 为 4TB，320G 为 5TB，480G 为 6TB。视频分发、大文件下载、镜像同步或高访问量图片站点会更快消耗流量。

如果业务依赖大量外部访问，最好先估算页面大小、月访问量和文件传输量。只看“1Gbps 端口”而忽略月流量，很容易高估方案容量。
